## 2025-05-14 - [Enhanced Sidebar Navigation and Accessibility]
**Learning:** Using `ListItemButton` with the `selected` prop and `Tooltip` for icon-only actions significantly improves navigation clarity and accessibility. Active state styling helps users maintain context of their current location within the application.
**Action:** Consistently apply active state styling to sidebar menus and add descriptive tooltips and ARIA labels to utility icons and icon-only buttons.
