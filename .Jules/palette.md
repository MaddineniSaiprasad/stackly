## 2025-05-15 - Enhancing Telemedicine Controls
**Learning:** Icon-only buttons in critical interfaces (like telehealth) need both visual tooltips for clarity and ARIA labels for screen readers to ensure safe operation. Destructive actions like "End Session" should always have a confirmation step to prevent accidental disconnection.
**Action:** Implement Tooltips and ARIA labels for Mic/Cam toggles and add a confirmation dialog for session termination.
